Personal Vehicle Assistant

A private, single-user integration that lets the vehicle owner's personal AI assistant read vehicle status and send basic commands (climate, seat ventilation, trunk, navigation destination, media) through the official Tesla Fleet API.

本项目是车主个人使用的私有集成，通过特斯拉官方 Fleet API 让车主的个人 AI 助理查询车辆状态并执行基础指令（空调、座椅通风、后备箱、导航目的地、媒体）。

  • Single user only; no data is shared with third parties.
  • Commands are signed end-to-end with the vehicle virtual key.
  • Public key: /.well-known/appspecific/com.tesla.3p.public-key.pem

仅限车主本人使用，不与任何第三方共享数据。
